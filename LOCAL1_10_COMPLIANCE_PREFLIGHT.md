## Public-source checks

### California Department of Insurance — Bulletin 96-08 / Insurance Code §1725.5
California Insurance Code §1725.5(a) requires specified licensees to include the license number on business cards, written price quotations, and print advertisements distributed exclusively in California for insurance products. The statute requires a size at least as large as any indicated phone/address/fax number or 12-point type (8-point for business cards), whichever is larger. Subsection (b) also requires the word “Insurance” at the specified size.

Source: California Department of Insurance, Bulletin 96-08, “Answers to Commonly Asked Questions on Insurance Code Section 1725.5.”  
https://www.insurance.ca.gov/0250-insurers/0300-insurers/0200-bulletins/bulletin-notices-commiss-opinion/bulletin-96-08.cfm

### California internet-advertising disclosure framework — Insurance Code §1726
The current California Legislative Information text for Insurance Code §1726 requires a California agent/broker who advertises and transacts insurance on the internet to identify the filed name, state of domicile/principal place of business, California insurance license number, and the word “insurance” on the home page or through a prominently displayed home-page link.

Primary statute: California Legislative Information, Insurance Code §1726.  
https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=INS&sectionNum=1726.

Primary statute for print disclosure: California Legislative Information, Insurance Code §1725.5.  
https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=INS&sectionNum=1725.5.

Final agency/compliance review should confirm that the deployed homepage presentation satisfies the statute’s same-size-type requirement and that the displayed license number is mapped to the correct named licensee(s).
